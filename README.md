# 🎓 Student Skill Analysis System

An intelligent web-based **Student Skill Analysis System** designed to analyze a student's technical skills, identify skill gaps, and provide personalized recommendations for improving their career readiness.

---

## 📌 About The Project

The **Student Skill Analysis System** helps students understand where they currently stand in terms of technical and professional skills.

The system analyzes information such as **skills, academic background, projects, certifications, and experience** to identify strengths and missing skills. Based on the analysis, it can provide recommendations for learning and career development.

The goal is to bridge the gap between **what students know** and **what the industry expects**.

---

## 🎯 Objectives

* Analyze a student's existing technical skills.
* Identify missing or weak skills.
* Compare student skills with required industry skills.
* Provide personalized learning recommendations.
* Help students prepare for internships and job opportunities.
* Improve career readiness through skill-based analysis.

## 🧩 Skill Gap Analysis

The system categorizes skills into different levels:

| Level             | Description                                         |
| ----------------- | --------------------------------------------------- |
| 🟢 Strong         | Student has good knowledge and practical experience |
| 🟡 Intermediate   | Student has basic knowledge but needs improvement   |
| 🔴 Weak / Missing | Skill requires learning or practical development    |

This allows students to clearly understand which areas they should focus on.

## 🚀 Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/student-skill-analysis-system.git
```

### 2. Navigate to the Project

```bash
cd student-skill-analysis-system
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

### 4. Activate the Virtual Environment

**Windows:**

```bash
venv\Scripts\activate
```

**Linux / macOS:**

```bash
source venv/bin/activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Configure Environment Variables

Create a `.env` file and add the required configuration:

```env
MONGO_URI=your_mongodb_connection_string
API_KEY=your_api_key
```

### 7. Run the Application

```bash
python app.py
```

Open:

```text
http://127.0.0.1:5000/
```
